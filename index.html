Usability and professional evaluation study

Explore a mobile AI code review application

This study evaluates Glance, an Android application that gives AI-assisted feedback on Dart and Kotlin code.

Why Glance is being studied

Most AI-assisted code review tools are made for desktop, IDE, or repository-based workflows. Glance investigates whether developers can review Dart and Kotlin code directly from a mobile application when a workstation is not available.

What you will do

  • watch a demonstration of the application
  • complete one guided hands-on task in the application
  • complete the System Usability Scale questionnaire
  • if you were invited as an SME, also discuss the feedback and classify six review findings before the application's category is revealed

For each finding below, look at the flagged line in the code, then give your own category guess before the application's answer is revealed.

Category reference card

  • Code Quality: correctness and structure, where the behaviour or structure itself is wrong.
  • Bugs: defects that could cause incorrect behaviour (logic error, null-reference risk, unhandled exception).
  • Optimization: efficiency — redundant code, unnecessary allocation, avoidable computational complexity.
  • Readability: how easily a human reader can follow the code.
